# Version Specification v1.1 (depends on kernel v1.0)

> [中文版](版本规范.md)

> **In one line**: each part keeps its own version number, and simply states in its title which kernel version it is built on.
> **Who it's for**: maintainers and implementers. Ordinary users don't need it — when you open a file, the format version in the file header is enough.

XiRang has several layers: the kernel (what a node is) sits at the bottom and changes most rarely; above it, the Template, the protocols, the implementations, and the error codes each move on their own. So that changes can be made layer by layer without dragging the others along, every layer keeps its own version number instead of one shared number tying everything together.

## Version Layers

| Layer | Carrier | Version | Bump rule |
|-------|---------|---------|-----------|
| Kernel | [README](https://github.com/outnever/XiRang/blob/main/README.en.md) (node / node value) | `vMAJOR.MINOR` | Bumped only on changes to the four fields / value encoding / file shell; MAJOR = breaking (old parsers can't read it), MINOR = compatible addition (e.g. a new type tag) |
| File format | The "format version byte" in the file | Monotonic (currently 1) | Follows kernel MAJOR |
| Template / conventions | [Template](https://github.com/outnever/XiRang/blob/main/spec/模板.en.md) | own `vX.Y` | Bumped independently |
| Implementation | `tools/` | own `vX.Y` | Bumped independently |
| Error codes | [Error List](https://github.com/outnever/XiRang/blob/main/errors/错误列表.en.md) | own `vX.Y` | Bumped independently |

## Dependency Declaration

Each peripheral document / implementation declares the kernel version it depends on in its title:

```
# Template v1.0 (depends on kernel v1.0)
```

- A kernel bump does **not** automatically bump peripherals.
- If a peripheral is confirmed compatible with the new kernel, only update its "depends on kernel" declaration; if changes are needed, bump its own version.

## What we don't do

- Don't encode dependencies into version numbers (no chains like `1.0-0.5-0.3`).
- Don't bump the kernel version because of peripheral changes.
