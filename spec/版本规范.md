# 版本规范 v1.0（依赖内核 v1.0）

> **一句话**：每一块各管各的版本号，只在标题里写清「我是基于哪个内核版本做的」。
> **给谁看**：维护者和实现者；普通使用者不必关心，用文件时看文件头里的格式版本就够了。

息壤分了好几层：内核（节点是什么）在最底下、也最稳；往上，模板、协议、实现、错误码各自发展。为了让每层的改动能分开做、互不牵连，息壤让每层留自己的版本号，而不是用一个总版本号把所有东西绑在一起。

## 版本分层

| 层 | 载体 | 版本 | 升版规则 |
|----|------|------|---------|
| 内核 | [README](https://github.com/outnever/XiRang/blob/main/README.md)（节点 / 节点值） | `vMAJOR.MINOR` | 只有四属性 / 值编码 / 文件外壳改动才升；MAJOR = 破坏性（旧解析器读不了）、MINOR = 兼容新增（如新增类型标记） |
| 文件格式 | 文件内「格式版本字节」 | 单调递增（当前 1） | 跟随内核 MAJOR |
| 模板 / 约定 | [模板](https://github.com/outnever/XiRang/blob/main/spec/模板.md) | 各自 `vX.Y` | 各自独立升版 |
| 实现 | `tools/` | 各自 `vX.Y` | 各自独立升版 |
| 错误码 | [错误列表](https://github.com/outnever/XiRang/blob/main/errors/错误列表.md) | 各自 `vX.Y` | 各自独立升版 |

## 依赖声明

每份外围文档 / 实现，在标题处声明所依赖的内核版本：

```
# 模板 v1.0（依赖内核 v1.0）
```

- 内核升版**不自动带动**外围升版。
- 外围若确认兼容新内核，只更新「依赖内核」声明；若需改动，升自己的版本。

## 不做的

- 不把依赖拼进版本号（不用 `1.0-0.5-0.3` 这种链式）。
- 不因外围改动而升内核版本。
